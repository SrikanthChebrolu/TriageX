# Skills

Project-specific slash commands / skills for TriageX.

Place `.md` files here to define custom slash commands available within this project.
Each file becomes a `/filename` command (without the `.md` extension).

## Format

```markdown
Your prompt or instructions here.
Use $ARGUMENTS to reference arguments passed to the command.
```

## Examples

- `triage.md` → `/triage` — run a triage analysis prompt
- `analyze-logs.md` → `/analyze-logs` — analyze log output
